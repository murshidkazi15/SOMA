# 🎵 SOMA — Interactive Music & Audio Web Platform

SOMA is a modern, high-performance web application built with **React**, **TypeScript**, **Vite**, **Tailwind CSS**, **Framer Motion**, **Spline 3D**, and **Supabase** for interactive music discovery, audio visualization, and playlist management.

---

## ✨ Key Features

- 🎧 **Interactive Audio Player & Controls:** Custom audio player with real-time playback, progression slider, and audio controls.
- 🎨 **3D Interactive Visuals:** Integrated Spline 3D scenes (`@splinetool/react-spline`) creating immersive visual experiences.
- ⚡ **Real-Time Data & Auth:** Powered by **Supabase** for backend data management, authentication, and playlist persistence.
- 💫 **Smooth Micro-Animations:** Fluid page transitions and micro-interactions built with **Framer Motion**.
- 📊 **Audio Analytics & Charts:** Interactive data visualizers using **Recharts**.
- 📱 **Responsive Glassmorphism Design:** Styled with Tailwind CSS, Shadcn UI primitives, and dark-mode themes.

---

## 🛠️ Tech Stack

- **Frontend:** React 18, TypeScript, Vite
- **UI Framework:** Tailwind CSS, Radix UI primitives, Lucide React, Framer Motion
- **3D & Graphics:** Spline 3D Runtime
- **Backend & Database:** Supabase (`@supabase/supabase-js`)
- **State & Data Fetching:** TanStack React Query

---

## 🚀 Getting Started

### Prerequisites

Ensure Node.js (v18+) is installed on your system.

### Installation & Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/murshidkazi15/soma-music.git
   cd soma-music
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```
